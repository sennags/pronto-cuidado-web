## Prompt Master Lovable

```text
Crie o protótipo inicial de uma aplicação web para uma instituição de saúde privada.

Objetivo:
Organizar o atendimento da clínica com foco em agendamento, cadastro de pacientes, controle básico de prontuário e gestão administrativa.

Público-alvo:
Pacientes, recepcionistas, médicos e administradores.

Perfis de acesso:
- Paciente: visualizar agendamentos e dados básicos
- Recepcionista: cadastrar pacientes e agendar consultas
- Médico: acessar prontuário e histórico do paciente
- Administrador: visualizar gestão geral e relatórios

Funcionalidades principais do protótipo:
- Login
- Dashboard principal
- Cadastro de pacientes
- Agendamento de consultas
- Lista de médicos
- Visualização básica de prontuário
- Tela administrativa com indicadores simples

Telas principais:
- Tela de login
- Dashboard
- Tela de pacientes
- Tela de agendamento
- Tela de prontuário
- Tela administrativa

Fluxo desejado:
Login > dashboard > escolha do perfil > acesso às funções principais do sistema.

Requisitos de design:
- Interface moderna, limpa e profissional
- Estilo visual confiável e acolhedor
- Cores suaves associadas à saúde, como azul, branco e verde
- Boa visualização em desktop e mobile

Requisitos importantes:
- Estruture o projeto de forma clara
- Organize navegação simples
- Use textos em português
- Priorize usabilidade
- Não precisa implementar integrações reais nesta primeira versão
- Não precisa implementar backend completo, apenas estrutura funcional de protótipo

Entregue uma primeira versão navegável, objetiva e bem organizada.
```
